# Шатун
**Что это:** стальной стержень, соединяющий поршень с коленчатым валом. Верхняя головка идёт на палец поршня, нижняя охватывает шейку вала через вкладыши.
**Аналогия:** голень ноги на педали велосипеда.
**Важно:** крышка шатуна крепится болтами, затягиваются строго по моменту.
**Связано:** [[Поршень]] · [[Коленчатый вал]]
