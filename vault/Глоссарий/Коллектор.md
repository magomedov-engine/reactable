# Коллектор
**Что это:** Труба-сборник: впускной подводит воздух к цилиндрам, выпускной собирает отработавшие газы. Выпускной крепят жаропрочным крепежом.
**Где увидите:** впускной обычно в развале между рядами цилиндров, выпускные по наружным сторонам рядов.
**Связано:** [[Турбокомпрессор]]
