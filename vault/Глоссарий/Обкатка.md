# Обкатка
**Что это:** Первые часы работы собранного двигателя. Холодная: проворот внешним приводом без топлива. Горячая: на стенде с нагрузкой по программе.
**Где увидите:** на испытательной станции: сначала проворот без топлива, затем работа на стенде; проверяют давление масла и течи.
**Связано:** [[Консервация]]
