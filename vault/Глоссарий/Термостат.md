# Термостат
**Что это:** Клапан-регулятор температуры охлаждающей жидкости: холодный двигатель идёт по малому кругу, горячий через радиатор.
**Где увидите:** в корпусе на выходе жидкости из двигателя (обычно спереди, где патрубок к радиатору).
**Связано:** [[Водяной насос]] · [[Рубашка охлаждения]]
