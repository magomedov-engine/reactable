# Распределительный вал (распредвал)
**Что это:** вал с «кулачками», которые вовремя открывают клапаны. Приводится от коленвала через шестерни (механизм газораспределения, ГРМ).
**Аналогия:** дирижёр, который говорит каждому клапану, когда открываться.
**Важно:** шестерни привода ставят строго по меткам.
**Связано:** [[Клапан]] · [[Коленчатый вал]]
