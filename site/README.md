# reactable — учебный сайт

Сайт для изучения курса «Слесарь механосборочных работ: сборка 12-цилиндрового дизеля».
Собирается из заметок Obsidian (папка `../vault`), бэкенда нет, хостинг на GitHub Pages.
Общее описание проекта и публикация: [../README.md](../README.md).

## Что умеет

- 18 уроков, 45 схем, 80 терминов, план на 2 недели.
- 3D-модель V12: 60 типов деталей (включая подключённый топливный фильтр с элементом и линиями к ТНВД, систему смазки с фильтрующим элементом и сверлениями вала и блока, систему охлаждения с крыльчаткой насоса, каналами рядов и головок, перепуском и радиатором, путь воздуха от фильтра через патрубки и каналы головок к клапанам, путь газов до выпускных труб, шатунные вкладыши, маслоприёмник, приводной ремень) с подробными карточками (как работает, как ставят, инструмент, типичные ошибки), анимация тактов, разборка, слои систем с бегущими потоками масла/воды/воздуха/топлива/газов, поперечный и продольный разрез, пошаговая сборка (16 шагов по технологическому маршруту), режим «Работа двигателя» («стеклянный» двигатель: впуск, впрыск, вспышка, выхлоп, газ в цилиндре по температуре, силы на поршне, график давления; эффекты включаются по отдельности), тренажёр «Найди деталь», метки ГРМ и регулировка тепловых зазоров. Раздел «Что показывать»: готовые наборы («Поршень и шатун», «Поршень + распредвал + коленвал», «Путь воздуха и газов», «Смазка», «Охлаждение» и др.), режим одного цилиндра и «глазок» у каждой детали в списке.
- Схемы открываются на весь экран: приближение колесом мыши, щипком двумя пальцами, двойным кликом, кнопками; листание стрелками и свайпом.
- Термины в тексте кликабельны: всплывает подсказка (на телефоне снизу выезжает панель).
- Поиск по всем урокам и глоссарию: `Ctrl+K` или `/`.
- Тест в каждом уроке: вопросы «Самопроверки» с вариантами ответа, по одному, варианты перемешиваются; после ответа пояснение, в конце разбор ошибок. От 80 % урок отмечается пройденным, лучший результат виден в шапке урока и на карточке. Формат вопроса в Obsidian: `> [!question]- Вопрос`, затем строки `> - [x] верный` / `> - [ ] неверный`, пустая `>` и пояснение. Вопрос без вариантов остаётся раскрывающейся врезкой.
- Итоговый экзамен (`#/exam`, день 14): билет из 30 вопросов всех уроков, из каждого урока хотя бы один; вопросы, на которых ошибались, попадают в следующий билет первыми. В конце — разбор по урокам «что повторить», история последних попыток.
- Карточки (`#/cards`): интервальное повторение (коробки Лейтнера: 1, 3, 7, 14, 30, 60 дней), не больше 10 новых в день. Колоды — факты из `vault/04_Практика/Карточки.md` (строки `вопрос::ответ`, их же понимает плагин Spaced Repetition в Obsidian) и 80 терминов глоссария. В меню видно, сколько карточек ждёт сегодня.
- Тренажёры (`#/trainers`): чтение штангенциркуля (нониус 0,1 и 0,05 мм) и микрометра на случайных показаниях с разбором, перевод единиц, порядок затяжки (крышка, фланец, условная головка, коренные крышки ЯМЗ-240 — проверяется правило «от центра, крест-накрест, по проходам», а не один порядок). Ссылки на них — в конце уроков про измерительный инструмент, момент затяжки, блок и единицы.
- «Первая смена и наставник» (`#/mentor`): чек-лист первой смены из `vault/04_Практика/Чек-лист_первой_смены.md` и вопросы наставнику, собранные из всех уроков; отметки «спросил», записанные ответы и свои вопросы; страница печатается.
- План по дням строится из поля `день:` в заметках уроков; в том же порядке идут боковое меню и кнопки «Назад / Дальше».
- Отметки «урок пройден», результаты тестов, прогресс и «Продолжить с места» (хранится в браузере).
- Оформление reactable: одна тёмная тема (графит и молочный), строгие углы; шрифты Oswald (заголовки), IBM Plex Sans (текст), IBM Plex Mono (подписи и цифры). Размер текста, оглавление урока с подсветкой текущего раздела.
- Блок-схемы Mermaid рисуются в браузере; на телефоне горизонтальные схемы разворачиваются вертикально.

## Запуск локально

```bash
npm install
npm run dev
```

`npm run dev` и `npm run build` сначала запускают `scripts/sync-content.mjs`: он копирует уроки, глоссарий и схемы из `../vault` в `src/content` (эта папка не хранится в git, она каждый раз собирается заново). Путь к хранилищу можно переопределить переменной `SLESAR_VAULT`.

Сайт использует hash-адреса (`#/lesson/...`) и относительный `base`, поэтому работает из любой подпапки GitHub Pages, а прямые ссылки на уроки не дают 404.

## 3D в уроках

Схемы из Obsidian (`![[файл.svg]]`) на сайте заменяются интерактивными 3D-блоками, если для схемы есть сцена. Исходная картинка остаётся во вкладке «Схема» блока. В заметках Obsidian ничего менять не нужно.

- **Заменить схему:** в файле группы `src/lessons3d/scenes/_group_*.js` у сцены указать `replaces: 'имя_схемы.svg'`.
- **Добавить 3D без схемы:** указать `inserts: [{ lesson: 'engine-03', heading: 'часть заголовка' }]`. Блок встанет после первого абзаца этого раздела.
- **Новая сцена:** файл `src/lessons3d/scenes/<id>.js` по контракту из шапки `stage.js`. Образец — `scenes/fit.js`. Сцены на полной модели двигателя описаны пресетами в `scenes/engine-scenes.js`.

Блок грузится, только когда до него доходит прокрутка, и освобождает видеокарту, когда уходит далеко за экран. В тексте урока колесо мыши листает страницу, а приближать модель можно в полноэкранном режиме. На телефоне модель вращается тоже только в полноэкранном режиме, чтобы палец листал урок.
