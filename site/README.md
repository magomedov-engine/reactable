# reactable — учебный сайт

Сайт для изучения курса «Слесарь механосборочных работ: сборка 12-цилиндрового дизеля».
Собирается из заметок Obsidian (папка `../vault`), бэкенда нет, хостинг на GitHub Pages.
Общее описание проекта и публикация: [../README.md](../README.md).

## Что умеет

- 18 уроков, 45 схем, 80 терминов, план на 2 недели.
- 3D-модель V12: 58 типов деталей (включая систему смазки с фильтрующим элементом и сверлениями вала и блока, систему охлаждения с крыльчаткой насоса, каналами рядов и головок, перепуском и радиатором, путь воздуха от фильтра через патрубки и каналы головок к клапанам, путь газов до выпускных труб, шатунные вкладыши, маслоприёмник, приводной ремень) с подробными карточками (как работает, как ставят, инструмент, типичные ошибки), анимация тактов, разборка, слои систем с бегущими потоками масла/воды/воздуха/топлива/газов, поперечный и продольный разрез, пошаговая сборка (16 шагов по технологическому маршруту), режим «Работа двигателя» («стеклянный» двигатель: впуск и наддув, впрыск, вспышка, выхлоп и турбина, газ в цилиндре по температуре, силы на поршне, график давления; эффекты включаются по отдельности), тренажёр «Найди деталь», метки ГРМ и регулировка тепловых зазоров. Раздел «Что показывать»: готовые наборы («Поршень и шатун», «Поршень + распредвал + коленвал», «Путь воздуха и газов», «Смазка», «Охлаждение» и др.), режим одного цилиндра и «глазок» у каждой детали в списке.
- Схемы открываются на весь экран: приближение колесом мыши, щипком двумя пальцами, двойным кликом, кнопками; листание стрелками и свайпом.
- Термины в тексте кликабельны: всплывает подсказка (на телефоне снизу выезжает панель).
- Поиск по всем урокам и глоссарию: `Ctrl+K` или `/`.
- Отметки «урок пройден», прогресс и «Продолжить с места» (хранится в браузере).
- Оформление reactable: одна тёмная тема (графит и молочный), строгие углы; шрифты Oswald (заголовки), IBM Plex Sans (текст), IBM Plex Mono (подписи и цифры). Размер текста, оглавление урока с подсветкой текущего раздела.
- Блок-схемы Mermaid рисуются в браузере; на телефоне горизонтальные схемы разворачиваются вертикально.

## Запуск локально

```bash
npm install
npm run dev
```

`npm run dev` и `npm run build` сначала запускают `scripts/sync-content.mjs`: он копирует уроки, глоссарий и схемы из `../vault` в `src/content` (эта папка не хранится в git, она каждый раз собирается заново). Путь к хранилищу можно переопределить переменной `SLESAR_VAULT`.

Сайт использует hash-адреса (`#/lesson/...`) и относительный `base`, поэтому работает из любой подпапки GitHub Pages, а прямые ссылки на уроки не дают 404.

## Устройство

| Путь | Что там |
|---|---|
| `scripts/sync-content.mjs` | Перенос материалов из Obsidian, манифест уроков, подписи схем |
| `src/lib/markdown.js` | Рендер markdown: врезки `> [!type]`, вики-ссылки `[[...]]`, вставки `![[...svg]]`, Mermaid, бейджи `~пример` |
| `src/lib/interactive.js` | Клики по терминам и схемам, ленивая отрисовка Mermaid |
| `src/lib/store.js` | Прогресс, тема, размер шрифта (localStorage) |
| `src/lib/search.js` | Поисковый индекс MiniSearch |
| `src/components/ImageViewer.vue` | Полноэкранный просмотр схем (@panzoom/panzoom) |
| `src/model3d/` | 3D-модель (three.js): `engineModel.js` — геометрия и кинематика, `features.js` — разрез и потоки, `operation.js` — режим «Работа двигателя» и упрощённая физика цикла, `partsInfo.js` / `partsDetails.js` — описания деталей, `assemblySteps.js` — сценарий сборки, `showPresets.js` — наборы деталей раздела «Что показывать», `systemRoutes.js` — маршруты систем |
| `src/lessons3d/` | 3D-блоки внутри уроков: `stage.js` — общий стенд (свет, материалы, подписи, стрелки), `registry.js` — реестр, `scenes/` — сцены и их группы `_group_*.js` |
| `src/components/Scene3D.vue` | Блок 3D в тексте урока: ленивая загрузка, шаги с пояснениями, пауза, весь экран, вкладка «Схема» |
| `src/views/` | Главная, урок, глоссарий, 3D-модель |

## 3D в уроках

Схемы из Obsidian (`![[файл.svg]]`) на сайте заменяются интерактивными 3D-блоками, если для схемы есть сцена. Исходная картинка остаётся во вкладке «Схема» блока. В заметках Obsidian ничего менять не нужно.

- **Заменить схему:** в файле группы `src/lessons3d/scenes/_group_*.js` у сцены указать `replaces: 'имя_схемы.svg'`.
- **Добавить 3D без схемы:** указать `inserts: [{ lesson: 'engine-03', heading: 'часть заголовка' }]`. Блок встанет после первого абзаца этого раздела.
- **Новая сцена:** файл `src/lessons3d/scenes/<id>.js` по контракту из шапки `stage.js`. Образец — `scenes/fit.js`. Сцены на полной модели двигателя описаны пресетами в `scenes/engine-scenes.js`.

Блок грузится, только когда до него доходит прокрутка, и освобождает видеокарту, когда уходит далеко за экран. В тексте урока колесо мыши листает страницу, а приближать модель можно в полноэкранном режиме. На телефоне модель вращается тоже только в полноэкранном режиме, чтобы палец листал урок.
